# 微信开发者工具演示指南

## 只想先看效果：双击浏览器版

1. 下载 `demo-v1` 分支最新ZIP，右键全部解压。
2. 在解压后的项目根目录找到 **`双击打开演示.html`**，双击，以Chrome或Edge打开。
3. 页面左侧可直接选择成员、新人报名、管理员；手机窄屏时三个按钮在页面顶部。
4. 无需微信账号、AppID、开发者工具、扫码、云服务或安装命令。所有数据为本机模拟，无真实支付。

浏览器版复用原生页面、处理器及业务引擎，不是微信正式上线版本。原生授权、支付和设备表现仍要在微信中单独验证。若浏览器限制本机存储，当次操作仍可使用，但关闭后记录可能不保留。

开发者通过 `npm run build:preview` 生成单文件。可选的 `node scripts/browser-smoke.js` 需要环境预装Playwright及Chromium（可用 `BROWSER_PATH` 指定浏览器），测试实际点击链路。当前执行环境的浏览器策略不允许file协议导航，自动化使用同一HTML的本机HTTP加载，已验证页面交互及无外部网络请求；最终电脑双击打开仍需用户实际确认。

## 导入

- 导入仓库根目录，使用微信开发者工具；无需启动网页服务器。
- `project.config.json` 已设置原生小程序目录和游客AppID。若工具版本要求测试AppID，可在本机私有配置中使用自己的测试号，不提交密钥。
- 保持 `miniprogram/config.js` 为 `mode: 'demo'`。默认所有操作在本机存储中完成。
- 首次启动使用当前北京时间作为模拟第8天，虚构成员第一周已有记录。屏幕上持续显示模拟标识。

## 路线一：成员打卡与身体记录

1. 默认成员林晓进入“今日”，看到当前训练周、剩余免打卡天数和第一周70元返款资格。
2. 选择快走，填30分钟，按实际演示勾选运动和饮食完成，选择晚餐时间，保存。
3. 再次提交仍算一天；取消一项后保存则为部分完成。
4. 点击免打卡会替换当日记录，不会同时算有效日。
5. 在“我的”填体重、可选腰围，查看历史条形和变化；记录使用公斤，不把斤与公斤混用。

## 路线二：陌生人报名

1. “我的 → 演示控制台”切换新报名用户，点击了解并报名。
2. 阅读健康告知、隐私、服务条款；分别勾选同意。未同意健康信息处理时不展示问卷。
3. 用虚构资料填写35—55岁年龄、身高、体重和昵称；六题都必须回答。
4. 任一题“是/不确定”：显示待评估，不能下单；此流程不提供医学放行。
5. 全部“否”且已确认服务条款：创建900元模拟订单，点击模拟成功，不会实际扣款。
6. 由于当前一期已经开始，新用户进入后续期次。可点击首页“演示：跳至我的开营日”开始记录。

## 路线三：心得与审核

1. 切回林晓，在“营友”发布文字或选填一张本机图片。内容显示待审，仅自己可见。
2. 切换周远，待审心得不会出现。
3. 切换管理员，进入管理台，通过该心得；切回周远，可看到并点赞、举报。
4. 管理员可以隐藏被举报内容，处理会写入审计记录。图片演示依赖开发者工具/设备相册及本机文件权限；云端图片上传与审核尚未提供。

## 路线四：周报与模拟退款

1. 切换管理员，选择“第1周”：林晓5个有效日达标，周远4个有效日未达标，首期分母为2人。
2. 复制CSV，仅包含打卡/返款汇总，不包含健康问卷。
3. 第一周已由虚构数据初始化结算。点“模拟发起退款”变为处理中，再点“模拟确认到账”变为已退款。
4. 重复操作不会重复生成70元记录。
5. 推进1天或7天，切回成员可记录新日期。最多两天免打卡；下一训练周重新提供两天额度。
6. 推进90天会结算已结束周期，不会为未记录日期虚构有效打卡。全周期达标900元的情况通过业务测试验证，无额外900元奖金。

## 路线五：暂停与争议

1. 成员在“我的”提交暂停/调整、系统故障或其他申请。
2. 管理员看到待处理申请，该成员暂不计周考核分母，未结算周期暂缓。
3. 管理员填写已沟通的处理结果；这是记录入口，不执行医学批准、自动延期、历史纠正或特殊退款。
4. 处理后可恢复按现有记录结算。特殊安排需要后续功能或运营流程承接，不能让用户误以为已自动延期。

## 重置与边界

- “我的 → 重置本机演示数据”恢复初始状态，清除当前模拟记录。
- 本机身份切换、日期跳转和重置只在本机演示服务提供；云服务身份来自微信上下文。
- 演示模式不能用于真实收费或真实健康服务，不输入真实病历或敏感信息。
- 若云环境配置错误，页面显示明确错误，不会自动切回模拟成功。
- 自动化Page测试通过不等于原生渲染、设备授权和支付平台已通过；请在开发者工具及目标设备完成导入、页面和相册实测。

## 新版首页与饮食体验

1. 首页查看鸿彬寄语，点“晨练打卡”填写活动与时长，保存后为部分完成。
2. 点“晚间打卡”，填写晚餐时间，确认三餐搭配和晚餐后未安排加餐；两项均完成后计一个有效日。
3. 点首页早餐、午餐或晚餐，先选一种推荐组合，一键保存即可。需要自选时展开“按喜好更换食材”。
4. 食材偏好改变会重置当前草稿，其他餐次如与新偏好冲突，首页提示调整。偏好过滤不代替过敏安全判断。
5. 每周两天免打卡、累计最多返900元、无额外结营奖金，均沿用原有规则。
